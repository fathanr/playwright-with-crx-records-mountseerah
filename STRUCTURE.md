## Key Directories

### `command/` - AI Rules
Contains all AI generation instructions and documentation. **Never delete**.

### `records-crx/` - Input
Save Playwright Codegen recordings here. AI reads from this directory.

### `pages/` - Generated
Page Object Models generated by AI from recordings.

### `tests/` - Generated
Test specifications generated by AI from recordings.

### `utils/` - Optional
Helper utilities for advanced scenarios. Can be deleted if not needed.

### `.auth/` - Runtime
Session storage, auto-generated on first run. Safe to delete (will regenerate).

## Workflow

1. **Record** → Save to `records-crx/`
2. **Generate** → AI creates files in `pages/` and `tests/`
3. **Run** → `npm run smoke`
4. **Commit** → Push to repository

## Template Usage

This is a **boilerplate template**. To use:

1. Clone this repository
2. Update `.env` with your credentials
3. Record your login flow
4. Generate tests with AI
5. Delete example files (optional)
6. Start building your test suite

## Example Files

These files are examples and can be deleted after you create your own:

- `records-crx/auth/login.record.ts`
- `pages/auth/Login.page.ts` (regenerate from your recording)
- `tests/smoke/auth/login.spec.ts` (regenerate from your recording)

## Protected Files

**Never delete** (see `command/CRITICAL_FILES.md`):

- `playwright.config.ts`
- `tests/auth.setup.ts`
- `command/` directory
- `.env`
- `package.json`
