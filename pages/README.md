# Page Objects

This directory contains Page Object Models generated from recordings.

## Structure

```
pages/
├── auth/
│   └── Login.page.ts               # Example: Login page object
└── <feature-name>/
    └── <FeatureName>.page.ts       # Your page objects
```

## Page Object Pattern

Each page object should:
- Encapsulate page elements (locators)
- Provide methods for user actions
- Use data-testid when possible
- Fall back to role/text selectors

## Example

```typescript
import type { Page } from "@playwright/test";

export class FeaturePage {
  constructor(private page: Page) {}

  // Locators
  get submitButton() {
    return this.page.getByTestId("submit-button").or(
      this.page.getByRole("button", { name: /submit/i })
    );
  }

  // Actions
  async submit() {
    await this.submitButton.click();
  }
}
```

## Generated by AI

Page objects are automatically generated when you:
1. Record a flow with Playwright Codegen
2. Use AI with `command/AI_MASTER_PROMPT.md`
3. AI extracts actions and creates page object

## Customization

You can manually edit generated page objects to:
- Add more helper methods
- Improve selectors
- Add validation logic
- Reuse across multiple tests
